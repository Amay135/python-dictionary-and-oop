# Python Dictionary and OOP

Repository ini berisi tugas pemrograman Python yang membahas konsep dasar struktur data Dictionary dan Object-Oriented Programming (OOP).

## Daftar Program

### 1. Dictionary Mata Kuliah

File:

```text
soal_1_232102016.py
```

Program menggunakan struktur data dictionary untuk menyimpan data mata kuliah.

#### Fitur

- Menampilkan data mata kuliah awal
- Menambahkan mata kuliah baru melalui input pengguna
- Menambahkan data mata kuliah secara otomatis
- Menampilkan seluruh isi dictionary

#### Konsep yang Digunakan

- Dictionary
- Looping
- Input Output
- Manipulasi Data

---

### 2. Simulasi Rekening Bank

File:

```text
soal_2_232102016.py
```

Program simulasi rekening bank menggunakan konsep Object-Oriented Programming (OOP).

#### Fitur

- Menyimpan saldo rekening
- Melakukan transaksi debit
- Melakukan transaksi kredit
- Batas maksimal transaksi kredit
- Batas limit transaksi
- Menampilkan saldo akhir

#### Konsep yang Digunakan

- Class
- Object
- Constructor
- Method
- Encapsulation
- Validasi Transaksi

---

## Teknologi

- Python 3

## Cara Menjalankan

Clone repository:

```bash
git clone https://github.com/username/python-dictionary-and-oop.git
```

Masuk ke folder project:

```bash
cd python-dictionary-and-oop
```

Menjalankan program pertama:

```bash
python soal_1_232102016.py
```

Menjalankan program kedua:

```bash
python soal_2_232102016.py
```
